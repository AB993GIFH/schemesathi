# SchemeSathi

A multilingual web app that helps people find the government schemes they qualify for.

**Live demo:** https://schemesathi-7u6x.onrender.com/

## Problem
Many people miss government schemes because the information is scattered, written in complex language, and mostly available in English only.

## Solution
Users answer four questions (age, income, occupation, gender) and instantly see matching schemes in English, Tamil, Hindi, or Urdu.

## Features
- Quick eligibility check
- 4 languages, including right-to-left Urdu
- Plain-language scheme summaries
- Mobile-friendly design

## Tech stack
Python (Flask), HTML, CSS, JavaScript, JSON data, hosted on Render.

## Note
The scheme rules in this demo are simplified. Always confirm eligibility on myscheme.gov.in.
